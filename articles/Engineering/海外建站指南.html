# 海外建站指南

覆盖：建站流程、平台选型、优缺点对比 整理时间：2026-10-29 适用对象：外贸工厂、跨境卖家、B2B 询盘型与 B2C 零售型企业

# 一、建站前先想清楚的三件事

# 1. 站点定位（决定一切选型）

类型目标核心指标典型代表
B2B 询盘站拿到客户邮件/WhatsApp 询盘询盘转化率、SEO 排名某外贸工厂官网（SaaS 搭建）
B2C 零售独立站直接在线成交收钱转化率、客单价、复购SHEIN 独立站、Anker 官网
品牌官网树立品牌形象、承接流量设计感、品牌信任度大卖的品牌门户

判断方法：客户是在网站上直接付款（B2C），还是看完要联系业务员谈（B2B）？两者功能完全不同，选型前必须定死。

# 2. 预算

  • 每年愿意花 500~2500 元（低成本托管）
  • 还是 3000~1 万元（国内主流 SaaS）
  • 还是有技术团队、想完全自主（开源自建）

# 3. 有没有技术能力 / 谁来维护

没有维护人手，就闭眼选 SaaS；有技术团队且要深度定制，考虑开源。

# 二、选型：四大阵营 + 主流平台

# 阵营 1：国际 SaaS（Shopify 为代表）

  • 技术栈：Ruby on Rails + Liquid 模板，全球工程成熟度天花板
  • 价格：年付基础版约 $29/月，高阶 $299/月，交易佣金 2%（用 Shopify Payments 可免）
  • 优点：
    • 生态最强：上万款应用、全球主题市场、支付/物流/POS 全打通
    • 稳定性和性能不用操心
    • 出海团队几乎人人会用，资料最多
  • 缺点：
    • Shopify Payments 需要海外主体，中国卖家收款要绕
    • 国内访问后台慢，官方中文支持弱
    • 应用费用叠加，长期成本不低
    • 数据在平台，被封号即归零
  • 适合：有出海团队、做 DTC 品牌零售、预算充足的卖家

# 阵营 2：国产出海 SaaS

# Shoplazza 店匠

  • 深圳团队，中国出海卖家用得最多的国产 SaaS，定位国际化
  • 月付 $28~$218 + 佣金 2%~0.2%，年付约八折
  • 模板设计感强，全球支付覆盖广（196 种本地支付、254 个国家/地区），中东等新兴市场本地化深，已上线 AI 建站 Agent
  • 短板：月费高于国内同行，深度定制（复杂 B2B、多仓）支持不足

# Ueeshop

  • 广州联雅出品，做了近二十年的老牌，主打 B2B 外贸官网
  • 年付制：标准版约 4800 元/年起，独立部署 6.8 万起，佣金 0.2%~0.5%
  • B2B 询盘功能全、SEO 基建扎实、中文一对一客服响应快
  • 短板：插件生态小、模板偏保守、设计自由度低

# ShopAgg（新兴小平台）

  • 一站式打包：建站 + 域名 + 企业邮箱 + 在线客服 + 自建访客统计
  • PHP 轻量技术栈（PHP 模板 + Tailwind，Nginx/Caddy 代理），每站独立环境、每日自动备份
  • ¥99~199/月，无交易佣金，四家门槛最低
  • 短板：生态几乎为零、功能深度有限、平台自身稳定性待验证

# 阵营 3：开源自建（WordPress + WooCommerce 为代表）

  • 软件完全免费开源，自己买服务器（VPS 约 $5~30/月）+ 域名（$15/年）+ SSL（免费 Let's Encrypt）
  • 优点：
    • 数据 100% 自有，随时迁移，无平台倒闭/封号风险
    • 无交易佣金，长期成本最低
    • 无限自由：PHP 生态 6 万+ 插件，B2B 阶梯价、订阅制、会员体系都能做
    • SEO 控制力最强（可精细化到每个 URL、Schema、站内结构）
  • 缺点：
    • 安全靠自己：插件漏洞、不更新被黑是最大软肋，需要持续维护
    • 上手有门槛：环境部署、主题调试、性能优化都要人管
    • 隐性成本易低估：外包改功能、修站的钱几年下来未必比 SaaS 便宜
  • 适合：B2B 询盘站（无在线支付、重内容+表单）、有技术能力、要长期经营、怕被平台卡脖子的团队

# 阵营 4：纯静态/手写（进阶可选）

  • 用 HTML/Astro/Next.js 手写官网，托管到 Cloudflare Pages / Vercel（免费额度足够 B2B 站用）
  • 成本趋近于零、性能极好、无任何依赖
  • 缺点：需要开发能力，内容更新要改代码或接 Headless CMS
  • 适合有开发团队的公司做品牌官网

  • 预算极低先跑起来 → ShopAgg 或 WordPress
  • 不想被任何平台绑定 → WordPress / 静态站

# 三、海外建站全流程（以 B2B 询盘站为例）

# 阶段 1：准备期（1~3 天）

  1. 确定定位与受众：B2B 还是 B2C？目标市场（欧美/中东/东南亚）？
  2. 注册域名：首选 .com，简短、含品牌词或核心产品词（如 your-product-supplier.com）；在 Namecheap/Cloudflare/平台方注册
  3. 规划内容架构：首页、产品列表、产品详情、About Us、Factory/案例、Blog、Contact——B2B 站这六类页面是标配

# 阶段 2：搭建期（3~7 天）

  1. 选定平台，按上面决策表选
  2. 选模板/主题：B2B 走工业风简洁风，B2C 重视觉转化
  3. 录入核心内容：
    • 产品页：高清图 + 英文详情（B2C）或参数/起订量/定制能力（B2B）
    • 信任要素：工厂实拍、认证证书（FDA/Halal/BRC 等）、合作案例
  4. 配置获客入口：
    • B2B：询盘表单 + WhatsApp 悬浮按钮 + 在线客服
    • B2C：支付通道（Stripe/PayPal/本地支付）+ 物流方案

# 阶段 3：SEO 基建（上线前必做）

  1. 技术 SEO：自定义 URL、Meta/OG 标签、canonical、robots.txt、sitemap.xml、移动端适配
  2. 结构化数据：JSON-LD（Organization / Product / FAQ），Google 富摘要靠它
  3. 提交 Google Search Console，申请收录
  4. 速度优化：图片压缩、WebP 格式、懒加载（海外用户对加载速度极敏感）

# 阶段 4：上线与合规

  1. HTTPS 强制（现代浏览器的底线）
  2. 隐私合规：GDPR 隐私政策页 + Cookie 同意横幅（面向欧洲必须做）
  3. 备案/主体：服务器在海外则无需国内备案；注意目标市场对食品/电子等品类的合规要求

# 阶段 5：获客运营（持续）

  1. 内容营销：Blog 定期更新行业内容（如 "How to source from Chinese factories"），这是 B2B 站自然流量的主要来源
  2. 数据分析：Google Analytics 4 或平台自带统计，看来源、热门页、询盘转化路径
  3. 再营销：Facebook/Google Pixel 埋点，广告再触达
  4. 持续迭代：根据搜索词和询盘数据优化页面与关键词

# 四、优缺点总结（SaaS vs 开源 一图看懂）

维度SaaS 建站WordPress/WooCommerce 自建
前期成本几乎为零软件 0 元，服务器+域名约 $100/年起
长期成本月费+佣金持续交无佣金，主要是运维人力
上手难度一两天上线有门槛，需技术或外包
维护责任平台全包全是自己的事
自由度受限模板和 API无限定制
数据所有权在平台手里完全自有
安全平台负责自己负责（最大风险点）
平台风险停运/封号/涨价（某平台 2021 年关停即前车之鉴）无

核心记忆点：SaaS 是租房——省心但房东说了算；WordPress 是盖房——自由但一切自己扛。

# 六、常见踩坑提醒

  1. 先选平台再定定位 → 本末倒置，返工成本极高
  2. 忽视移动端 → 海外移动流量占比 60%+，模板必须响应式
  3. B2B 站照抄 B2C 模板 → 放购物车没有意义，询盘入口才是生命线
  4. 不做 SEO 基建就投广告 → 广告停了流量归零，自然流量才是资产
  5. 忽略隐私合规 → 欧洲 GDPR 罚款是真实风险
  6. 图片直接上传原图 → 加载慢 1 秒，转化率掉 7%
  7. 把宝押在单一平台 → 重要内容（产品数据、客户邮件列表）自己留备份

本文档基于 2026-10 对各平台官网、报价页及若干真实站点的实测调研整理。
